# Camper Cafe Menu

A simple, responsive cafe menu webpage built with HTML and CSS. The page features a coffee and dessert menu, prices, and a warm cafe-inspired background.

## Preview

Open `index.html` in your browser, or enable GitHub Pages to host it online.

## Built with

- HTML5
- CSS3

## Project files

- `index.html` — menu content and page structure
- `styles.css` — layout, typography, colors, and styling

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
